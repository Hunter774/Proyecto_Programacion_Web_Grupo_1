
# Proyecto Final Programación Web
**Tienda en Linea - Xucle-Bits**

## Equipo
- Roberto Antonio Matamoros (Grupo 1)

## Objetivo
Diseñar e implementar una aplicacion web funcional para una tienda en línea de **tecnologia**, integrando los conceptos aprendidos durante el curso.

## Estructura del Proyecto
Proyecto_Programacion_Web_Grupo_1/
│
├── index.html              # Página principal con catálogo
├── style.css               # Estilos generales
├── componentes/
│   └── carrito.html        # Diseño del carrito de compras
│   └── carrito.css         # Estilos específicos del carrito
├── icons/
│   └── icono.png            # Logo de la tienda
└── README.md               # Documentación del proyecto

## Paginas diseñadas (Avance I)
- **Index.html** → Catalogo de productos con navegacion y pie de pagina.  
- **Carrito.html** → Vista del carrito con productos, opcion de eliminar y botón de comprar.
